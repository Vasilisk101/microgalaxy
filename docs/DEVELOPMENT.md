# Разработка

## Требования и команды

Node.js 22.13 или новее. Из корня репозитория:

```bash
npm ci
npm run dev
npm test
npm run typecheck
npm run build
```

`dev` и `build` сначала собирают страницы симуляторов. Отдельная сборка 0.8 и интерфейса `/v1`:

```bash
node simulator-v08/build.mjs
```

Этот скрипт создаёт HTML в `simulator-v08/dist/` и `simulator-v1/dist/`. Маршрут `app/v1/route.ts` отдаёт собранную страницу версии `/v1`. Команды тестирования запускают проверки различных поколений; выполненный тест отдельного модуля не равнозначен полной проверке сайта или публикации.

## Устройство проекта

| Путь | Назначение |
| --- | --- |
| `simulator-v08/src/` | Общее симуляционное ядро, география, экономика, хроника, хранение и базовый интерфейс. |
| `simulator-v1/src/edition.mjs` | Подключение модели 1.0.1 к базовому ядру и совместимость версий. |
| `simulator-v1/src/living-world.mjs` | Бассейн, проекты, следы, память и проверка их состояния. |
| `simulator-v1/src/space-world.mjs` | Тела, колонии, полёты, сообщения и проверка космического состояния. |
| `simulator-v1/src/branches.mjs` | Условия и проверка контрольных ветвей. |
| `simulator-v1/src/place-records.mjs`, `place-time.mjs` | Записи места и доступность исторического перехода. |
| `simulator-v1/src/place-landscape.js`, `place-focus.js`, `place-visit.js` | Реконструкция, экран места и управление посещением. |
| `simulator-v1/tests/`, `simulator-v08/tests/` | Проверки моделей и поведения интерфейса. |
| `app/`, `lib/` | Маршруты сайта, хранение и серверная обвязка. |

Сборщик объединяет исходники браузерного симулятора в общий контекст. Имена файлов и API ниже относятся к исходникам, а не к публичному сетевому интерфейсу.

## Полезные точки интеграции

- `LivingWorld.summary(world, year)` возвращает доступные сведения живого мира; `LivingWorld.validate(world)` проверяет состояние.
- `SpaceWorld.targetOptions(world, originId, engineering, year)` описывает варианты целей; `SpaceWorld.validate(world)` проверяет космические данные.
- `PlaceRecords.placeRecords(world, regionId)` собирает записи места; `PlaceTime.canVisit(live, year)` проверяет доступность исторического перехода.
- `PlaceFocus.open(host, controls)`, `refresh()` и `close()` управляют экраном. `controls.get()` поставляет выбранные данные и доступные годы; `controls.onAction(action, value)` обрабатывает выход, закрепление и переходы времени.
- `PlaceLandscape.draw(canvas, world, region, options)` рисует условную сцену по состоянию; это не источник дополнительных физических объектов.

Модель 1.0.1 подключается через `edition.mjs`; сохранения 1.0.0 обрабатываются с сохранением их правил. При изменении моделирования проверяйте версию мира и совместимость старых сохранений, а при изменении интерфейса — отсутствие будущих данных в историческом представлении.

## Хранилище и публикация

Локальный архив использует возможности браузера; облачная часть требует настроенного окружения, авторизации и соответствующих привязок. Ошибка облака не должна представляться отсутствием локальных миров. Секреты и пользовательские сохранения не входят в репозиторий. Развёртывание и проверка доступа к опубликованной версии выполняются отдельно от локальной сборки.
